# Architecture

Expo Router screens use TanStack Query for server data, Zustand for session state, SecureStore for credentials, and FastAPI for authenticated operations. The API separates validation, record ownership lookup and audit helpers from the HTTP routes, with SQLAlchemy 2 models and Alembic migrations. PostgreSQL stores operational records. Airflow invokes a Python pipeline that reads a consistent snapshot, writes changed records to MinIO as Parquet, validates and aggregates records with Pandas, and atomically replaces curated PostgreSQL tables. Analytics endpoints read curated tables; the dashboard reads current operational records directly. The two sources are displayed separately, not summed together. Curated responses include their refresh timestamp.

Live daily totals use the user's IANA time zone. Curated analytics group by UTC day; they can therefore differ around local midnight. The dashboard's recent reading list is limited to 100 records. Notifications are scheduled locally and use the device's time zone; they are not a medication-delivery or adherence system. Incomplete integration and operational risks are listed in the README and security document.
