# Security and privacy

This prototype is **not ready for real patient information** and has not been assessed for HIPAA, GDPR, or any other healthcare or privacy regulation. No compliance claim is made. Users must be given a tracking-only disclaimer and clinician-provided targets; no dosing advice or delivery is implemented.

Implemented controls include Argon2 password hashing, short-lived JWT access tokens, rotating refresh tokens, parameterized SQL, record ownership checks, input validation, an in-process authentication rate guard, environment-supplied secrets, SecureStore tokens, and metadata-only audit events. Audit events omit health payloads. Local HTTP is deliberately used only for synthetic data. A deployment needs TLS for all network paths, managed secrets and rotation, encrypted storage and backups, restricted network access and least-privilege service accounts, hardened containers, stronger authentication and recovery, proxy-aware distributed abuse prevention, audit retention and access controls, threat modeling, incident response, accessibility and clinical safety review, consent and data governance, and independent security testing.

Deletion currently removes operational and curated database rows, but **does not delete data already stored in MinIO, failed batches, or backups**; audit metadata remains. Notification schedules may remain on a device after deletion or logout, and enabled reminders do not synchronize notifications across devices. Export through the mobile share sheet hands sensitive content to the selected destination. Local object storage has root credentials shared with the pipeline and no retention policy. Avoid production use until deletion, export, authorization, secrets, notifications and backups are redesigned and verified end to end.

The mobile dependency audit reported four high-severity findings involving `decode-uri-component`, `query-string`, `image-size`, and `postcss`. Some fixes require an Expo/toolchain upgrade or compatibility review. Re-run `cd mobile && npm audit --omit=dev` and remediate before deployment.
